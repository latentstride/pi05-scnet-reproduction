# π₀.₅ 项目工作清单：环境部署与官方复现

> **阶段目标**：在租赁 GPU 平台部署 OpenPI，加载 π₀.₅ 官方 `pi05_libero` 权重，完成模型推理与 LIBERO 仿真闭环，建立后续跨本体后训练实验的可复现基线。
>
> **阶段范围**：本阶段只进行官方模型推理、闭环评测与实验整理；暂不开展异构数据混合训练、跨本体微调或消融实验。

## 任务一：GPU 服务器环境检查

- [ ] 确认 GPU 型号、显存、租赁价格与磁盘空间
- [ ] 检查 NVIDIA 驱动、CUDA 相关运行环境
- [ ] 检查 Python、Git、Docker 是否可用
- [ ] 确认 GPU 可被深度学习框架识别
- [ ] 确认数据与模型权重的持久化存储位置
- [ ] 记录服务器配置和软件版本

**验收标准**：GPU 正常工作，服务器满足 π₀.₅ 推理要求，关键环境信息已记录。

## 任务二：OpenPI 官方环境部署

- [ ] 克隆 OpenPI 官方仓库：https://github.com/Physical-Intelligence/openpi
- [ ] 初始化 Git 子模块
- [ ] 固定并记录仓库 commit
- [ ] 安装 uv 和官方说明所需项目依赖
- [ ] 检查深度学习框架与 CUDA 依赖的兼容性
- [ ] 验证 OpenPI 核心模块能够正常导入
- [ ] 保存环境配置与安装命令

**验收标准**：OpenPI 环境部署成功，核心模块可以正常运行，能够重新搭建相同环境。

## 任务三：π₀.₅ 模型加载与推理验证

- [ ] 下载并缓存官方 `pi05_libero` checkpoint
- [ ] 使用匹配的模型配置加载权重
- [ ] 核对模型输入格式：图像、机器人状态、语言指令
- [ ] 读取真实 LIBERO observation，检查输入字段与形状
- [ ] 执行一次前向推理
- [ ] 检查输出动作的维度、数值及反归一化结果（无 NaN / Inf）
- [ ] 记录模型加载时间、GPU 显存占用与推理耗时

**验收标准**：π₀.₅ 能基于符合官方接口的观测生成合法的动作序列，并保存推理验证记录。

## 任务四：LIBERO 仿真环境部署

- [ ] 参考官方 LIBERO 评测说明：https://github.com/Physical-Intelligence/openpi/blob/main/examples/libero/README.md
- [ ] 安装或启动 LIBERO 及所需依赖
- [ ] 配置 MuJoCo 仿真与云服务器离屏渲染
- [ ] 验证 LIBERO 场景能够正常加载
- [ ] 验证机器人状态和摄像头图像可以读取
- [ ] 验证动作能发送到仿真机械臂
- [ ] 配置 π₀.₅ 策略服务与仿真客户端的通信（按照官方流程）

**验收标准**：LIBERO 仿真环境可以正常运行，并与 π₀.₅ 模型完成输入输出通信。

## 任务五：π₀.₅ 闭环控制验证

- [ ] 选择一个 LIBERO 操作任务
- [ ] 初始化机器人、任务场景与初始状态
- [ ] 将图像、机器人状态与任务指令输入 π₀.₅
- [ ] 获取模型预测的动作序列
- [ ] 按官方动作执行协议在仿真中执行动作
- [ ] 连续运行“观测 → 推理 → 动作 → 新观测”闭环
- [ ] 运行完整 episode，直到成功、失败或达到步数上限
- [ ] 保存任务结果、动作轨迹、运行日志和演示视频

**验收标准**：π₀.₅ 能完整控制 LIBERO 机械臂完成一个闭环 episode（无论成功与否，均需有明确终止与完整记录），而不是只完成单次前向预测。

## 任务六：小规模基线评测

- [ ] 固定 3 个 LIBERO 任务
- [ ] 每个任务选择 5 个可复现的初始状态
- [ ] 共运行 15 个 episode
- [ ] 记录每轮任务的成功或失败、终止原因与执行步数
- [ ] 计算各任务成功率和总体成功率
- [ ] 保存机器人状态和模型输出动作序列
- [ ] 整理代表性的成功与失败案例
- [ ] 检查状态表示、动作表示、控制方式及坐标系定义
- [ ] 保存评测配置、随机种子与全部结果

**验收标准**：完成 15 轮受限闭环评测，生成成功率统计、动作日志和仿真视频。

> **说明**：15 轮评测是小规模功能性基线验证，不等于统计意义上的官方 LIBERO 全量 benchmark 复现；不要直接将其与官方报告的完整 benchmark 成功率作严格比较。

## 任务七：复现结果整理与归档

- [ ] 整理完整环境配置与安装步骤
- [ ] 保存 OpenPI commit、模型权重标识及依赖版本
- [ ] 整理模型推理、策略服务和仿真评测运行命令
- [ ] 汇总 LIBERO 评测结果与成功率统计图
- [ ] 记录机器人状态空间、动作空间与相关数据字段
- [ ] 记录末端位姿、坐标系约定、动作类型与控制接口
- [ ] 整理 README、实验报告及演示视频
- [ ] 根据保存的代码与配置重新运行至少一次关键实验

**验收标准**：形成可复现的 π₀.₅ 官方推理与 LIBERO 仿真基线，为跨本体后训练提供可靠起点。
