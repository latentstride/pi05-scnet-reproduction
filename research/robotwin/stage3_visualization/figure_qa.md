# 样例图验证

目标：一条已归档 episode 的 RGB 与记录曲线可追溯到同一文件/帧；不把图中序号解释为真实时间，不把目标值解释为实际 qpos。类型：image plate + quant；三视角图、14 维关节目标曲线、14 维末端位姿曲线。

依据用户指定的首尾帧和曲线要求直接实施。LineTrend/plot_trend.py 已检查，其累积论文数、日历和事件标注与机器人数据不兼容；保留简洁线条/双列布局，使用统一 typography、color、export 基线。183 mm 宽，PDF 矢量线条 + 300 dpi PNG + 可编辑 SVG，Arial 字体。英文标签保留源字段名称。左/右固定蓝/红，并有文字和分列区分。

- Pass 0：无默认色板、无四边框、无装饰网格、无图内遮挡图例。
- Pass 1：全部 295 帧，28 个数值通道，不降采样、不平滑、不做累计；数据有限；源单位约定见契约。CSV 按帧输出。三视角取 0、147、294 帧，9 张原分辨率 PNG 单独保留。
- Pass 2：夹爪与关节分面、位置和四元数分面；不在同一 y 轴混合单位。双列直接标明左右臂。图标题指明 recorded_joint_target / recorded_endpose。没有统计显著性或成功率推断。
- Pass 3：已渲染检查，曲线可读，标签完整；首轮三视角图行间标题偏近，已增加行距重绘。所有图均以 frame index 标注，无秒轴。图像不改色、不调对比度。传感器内容导致大面积亮背景，保留原图，不套用统计散点的内容密度阈值。

绘图数值、语言、HDF5 和导出文件哈希见 provenance.json；原始 HDF5 不上传 GitHub。
