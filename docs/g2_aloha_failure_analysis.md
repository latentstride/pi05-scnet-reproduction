seed0-w4 的左臂接近并在动作 178 首次发出闭爪目标，22/75 个四动作前缀包含左闭爪。抽样帧显示左手靠近、部分遮挡并改变物块姿态，缺少历史对象高度和双指接触数据，不能认定曾经稳定提起。第 34 次查询、仿真 33.120 秒首次超过 50 mm 跟踪误差。后段左手重新打开，右手没有闭爪，未完成交接和放置。最终实测与驱动目标的自碰撞检查均通过，说明自碰撞并非四次失败的统一解释。

seed1-w1 的两臂逐渐靠近物块，视频后段显示物块被挤倒或横置。300 个执行前缀的左爪目标最低仍为 0.981184。292/300 个动作块预测未来左闭爪，最后十块的闭爪位置仍在第 12–22 行，实际只执行第 0 行。查询 149、物理 tick 11491、仿真 45.964 秒首次超过 50 mm 跟踪误差。最终两臂与对侧腕部/相机附近的几何出现重叠，自碰撞检查拒绝实测和驱动目标。没有主动右闭爪、独立右持有或释放证据。

seed1-w4 跟踪 RMSE 仅 6.928 mm，最大 17.708 mm，仍然失败。73/75 个动作块预测未来左闭爪，最后十块闭爪位于第 16–27 行，四动作前缀一直近乎全开。视频显示双臂接近、挤压和倾斜物块，最后仍靠近原区域。最终实测与目标的自碰撞检查均发现对侧指/腕相机附近重叠。该试次说明大跟踪误差不能单独解释所有失败。

视频与几何复核的证据位于 failure-audit-127054052-r1/frames、offline-repair-20261106-r1/final-frames 和 native-self-127054052-r1/native-self.json。自碰撞检查使用原 URDF 和 MPLib，只有机器人几何，没有任务对象或动态推进。它说明记录状态在该几何规则下重叠，不能替代原始 PhysX 接触证据或精确归因跟踪误差。首次 50 mm 偏差处的实测和目标自碰撞检查均通过，故不能把早期跟踪偏差全部归因于这些最终自碰撞。

MODEL_BEHAVIOR 有直接动作证据支持。短执行窗口反复丢弃包含闭爪的动作块后缀，造成抓取阶段进展不足。更长窗口保留这些目标的静态统计见反事实报告，但新窗口会改变后续图像和模型输出，当前资料无法证明扩大窗口便会成功。

CONTROL_TRACKING 已确认三个试次存在明显偏差，不能据此判定控制器代码存在确定性错误。750 份原生计划与冻结前缀变换逐值一致，原生 take_action 使用关节空间 TOPP 并跟随驱动目标，未发现重复执行增量、左右臂互换或单位换算错误。

OBSERVATION_SEMANTICS 与 ACTION_SEMANTICS 已核查固定源码。PACE 输入直接使用 joint_action/vector，原 Robot.get_left/right_arm_jointState 返回 drive_target 与归一化夹爪，G1/G2 的原生输入均沿用该合同。实际关节和驱动目标不同不构成更换输入语义的依据。OpenPI 配置 adapt_to_pi=False、use_delta_joint_actions=True，策略输出变换已经恢复绝对动作，G2 对输出仅做原约定前缀选择和有界夹爪截取。

PROMPT_DISTRIBUTION 存在受控因素变化。G1 提示为 “Grab the red block with the left arm.”，G2 为 “Pick up the red block with the left arm, hand it to the right arm, and place it on the target.”。后者扩展到完整任务，但没有同状态同随机条件下的模型对照，不能确定它是根因。该因果对照标为 GPU_DEFERRED。

EPISODE_BUDGET 不是单纯时间不足的已证实解释。对应专家包含 295/277 帧，物理时长 15.78/14.62 秒，原生专家 CPU 回放成功。策略试次的 300 动作覆盖 65.78–81.54 秒，约为专家物理时长的 4.5–5.2 倍。策略无需逐帧模仿专家，但在更长时间中仍未执行关键闭爪，不能仅靠增加动作上限解释或修复失败。
