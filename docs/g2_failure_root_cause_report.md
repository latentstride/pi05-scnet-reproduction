本轮完成作业 127054052 的证据归档、Aloha 0/4 行为分析、ARX 四事件 CPU 复现、工程修复与回归。当前判断为 **GPU_DEFERRED**。已确认的工程缺陷集中在评分标记和留证，策略行为仍存在需要闭环验证的风险，原配置重复运行的价值不足。

Aloha 的主要直接失败机制是抓取阶段进展不足。seed0-w1、seed1-w1、seed1-w4 的执行前缀始终没有左手闭爪，四次均没有右手闭爪。与此同时，动作块大多在未来预测了左闭爪，窗口1/4反复丢弃相应后缀。seed0-w4在第178个动作索引闭过左爪，后续重新打开，没有完成右手独持与放置。三次存在明显跟踪偏差，另一次跟踪较好仍失败，故不存在单一的跟踪误差解释。

ARX的四次终止分别如下。

- seed0-w1执行25个动作后，目标ARX左指1在候选工具位姿上与物块相交。CPU重建深度5.680498 mm，原规则允许2 mm。
- seed0-w4执行24个动作后发生同一类目标指—物块拒绝，重建深度2.752330 mm。
- seed1-w1执行56个动作后，在下一次观测映射的虚拟Aloha左腕fl_link4–fl_link6处碰撞。下一次模型推理没有发生。
- seed1-w4首个模型目标使右臂link2–link5自碰撞，零动作执行。实测初态和首次观测映射此前通过。
