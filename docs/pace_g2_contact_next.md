# G2 后续接触控制实现约束

最新实现与实测见 [第四轮接触控制](pace_g2_contact_stage4.md)。下文方案审查记录保留其产生时的状态；接触原型现已接入诊断链，完整策略闭环尚未通过。

前置证据：第三轮已通过双向 IK、实网格连接路径、原生/ARX 入口的 CPU 导入，以及独立 Aloha 代理碰撞世界的障碍物刷新检查。下一步处理接触和持物，继续 CPU 开发，不申请 GPU。

1. 保持已审计的本体 self-ignore 与任务接触规则独立。ARX 的同实例连杆规则来自固定资产，不能扩展成跨臂或环境豁免。
2. 模型的“关闭夹爪”是驱动意图。抓住有体积物体后，实际指关节通常无法到达空夹爪的闭合端点。碰撞几何、实际状态与驱动目标须分别记录；不能对任意深度的手指/物体穿透一律放行，也不能把未到达闭合端点自动当作传感器错误。
3. 保留模型闭合意图，以有限力的位置驱动配合速度/加速度约束执行。不要把首次接触位置直接改成驱动终点：这会消除位置误差并可能降低持续夹持力。接触几何预测仅用于碰撞检查，与最终驱动目标分字段记录。仅针对明确的 gripper link–block 配对设计有界接触许可；手掌/物块、另一臂、环境与深穿透继续拒绝。未经接触处理的现有 strict 模式仍是诊断控制路径。
4. 持物预测必须将物体几何随持有手的候选 TCP 移动，并检查物体与环境/另一手臂的关系。固定在当前世界位姿的 free-object 碰撞模型不能覆盖提起和运输。
5. 交接状态应依据实际双方接触、夹爪和物体状态建立，明确接收手接稳、给出手释放的顺序。窗口 4 可能包含多个事件，不能在规划时假定未来接触已经发生。
6. 先用 CPU 单元测试及真实网格/必要的 CPU 物理夹具验证几何与事件协议。真实任务的渲染、接触动力学、跟踪及完整模型 episode 留在获批的唯一综合 GPU 分配中验收。
7. 接触路径通过后，补齐正式初态列表、schema/run_lock 凭证、资源预算和单入口发布。当前诊断配置的 500 动作/600 秒不是冻结实验预算。

## 2026-11-05 方案审查

采用“意图、驱动、几何预测、实测”四类值分离：

| 字段 | 用途 |
| --- | --- |
| 原始策略夹爪值 | 保留模型输出，供复查 |
| 标定后驱动目标 | 继续表达闭合意图，经过端点、速率及力上限限制 |
| 预测接触开度 | 搜索候选姿态的首次接触几何，只用于规划检查 |
| 实际指关节位置 | 真实物理状态，用于碰撞刷新、执行监测及实际状态日志 |

物块挡住时，目标为 0、实测大于 0 可以是正常接触；不能仅凭目标误差判定跟踪失败，也不能仅凭开度未到 0 判定已抓稳。抓持状态需要持续双指实际接触、有效冲量和物块相对工具位姿稳定共同确认。相对位姿滑移超限、接触丢失或非许可碰撞必须形成失败记录。

规划从当前实测开度出发，检查闭合扫掠到首次物块接触；携物运动用接触开度预测手指几何，同时检查随持有手移动的物块。多 waypoint 前缀遇到尚未发生的抓持/交接事件时分段执行并重新观测，不能预先把后续路径视为已经持物。

原生 PACE 的 `get_normal_real_gripper_val()` 实际读取 `get_drive_target()`。策略输入中的夹爪字段须按源接口明确选择命令语义或实测语义，且两者都留证；碰撞几何始终使用物理实测/明确的接触预测。此差异需要在正式实验协议中固定，避免 A/B 条件混用。

SAPIEN 提供 `set_drive_property(..., force_limit=..., mode="force")`。力上限、接触深度、稳定时长、滑移和双持闭链容差需要实验标定；`g2_contact.py` 现有默认值仅为未接线的开发原型，不作为已验收配置。CPU 闭合试验使用固定物块，对照空夹爪、默认驱动力上限以及 0.5 N/2 N 试验值；这些值不是设备额定参数，也不是最终选定的夹持力。试验脚本为 `scripts/g2_grip_drive_probe.py`。

参考：[SAPIEN PhysX 驱动接口](https://sapien-sim.github.io/docs/api/sapien.pysapien.physx.html)。该 CPU 试验不覆盖动态提起、运输、交接或完整模型闭环。

## CPU 实测结果

证据目录：`research/g2/grip-drive-probe-20261105/`。使用固定 ARX 碰撞网格、SAPIEN 3.0.0b1 的 PhysxCpuSystem，每条件 750 个 4 ms 物理步；无 renderer、无 GPU 分配。固定物块，夹爪以相同斜坡从 44 mm 命令至 0，再保持。下表实际位置及接触力均为最后 100 步均值，接触力按接触冲量模长除步长估计。

| 条件 | 单指驱动力上限 | 实际两指位置（mm） | 两指接触力估计（N） |
| --- | --- | --- | --- |
| 空夹爪 | 2 N | 0.030 / 0.029 | 无接触 |
| 固定物块 | 默认上限 | 29.707 / 29.479 | 11.12 / 14.23 |
| 固定物块 | 0.5 N | 29.599 / 29.594 | 0.49 / 0.52 |
| 固定物块 | 2 N | 29.600 / 29.593 | 1.99 / 2.03 |

三组夹物条件最后 100/100 步均为双指接触；全程与物块接触的连杆仅为 link7/link8。0.5 N、2 N 条件全程最大接触穿透分别约 0.000089 mm、0.000285 mm。这些值描述本夹具求解器输出，不可直接用作完整场景的穿透阈值。

试验支持采用有限力的位置驱动并保留闭合目标。固定物块不能验证抗重力、摩擦、滑移或交接能力，最终力上限仍待动态夹具标定。原始逐步日志保留在 provenance.json 所列远端个人目录，已记录 SHA-256；汇总回读与源码哈希校验一致。本地现有 85 项回归通过，未宣称未接线接触原型通过动态验收。
