# AI 辅助开发的可查记录

1. 用户指定固定 revision 的 100 条专家轨迹、既有 FK/IK、ECharts 离线页面和 PPT，明确只使用 CPU，并要求保留失败。
2. Codex 新建批量下载入口并调用原 HTTP Range 类。第一次请求读取归档目录遇到 URLError，原日志保存在 logs/download-run.log。改用明确的系统 CA 文件后重试，先核对响应状态和 Content-Range，再逐成员查 CRC 与 SHA。
3. Codex 运行数据审计并用独立合成样本检查缺相机、损坏 HDF5、NaN、夹爪越界和图像解码失败。合成样本仅进入测试临时目录。
4. 用 2,000 个目标验证算法包装与数据管线，再对全部 47,628 个目标执行同一有限搜索。完整表保留 87 个未解。报告核对了方向、侧别、误差单位、分母和未验证的执行条件。
5. Dashboard 使用 Python 输出的 JSON，并在 file:// 下用同源 data.js 载入，避免浏览器限制本地 fetch。首版把轨迹绝对数量和帧占比放在同一轴，调整为同单位百分比。现有页面浏览器日志、导出 CSV 和四个实际截图随附。

历史作业、控制器和数据日志是仓库已有的独立证据。展示材料采用本次实际开发过程，没有把历史聊天截图补画成证据。
