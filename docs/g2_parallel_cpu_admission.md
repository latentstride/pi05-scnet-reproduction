# G2 七项 CPU 准入

在 SCNet 已有 Linux 物理容器中隐藏 CUDA，以 SAPIEN CPU PhysX、作者原生 TOPP、现有资产及固定模型响应运行。真实计算包括场景复位、物体与机器人状态、关节、接触、FCL 初态、动作消费及资源停止。相机像素为无渲染占位，真实 RGB、JAX 推理和 GPU 进程退出留到各自正式分配。

| 作业 | CPU 准入 | 实际证据 |
| --- | --- | --- |
| G1 | 通过 | 场景 100000，初态与几何核验，50 行后第二次请求。 |
| G2 | 通过 | 场景 200000，初态与几何核验，50 行后第二次请求。 |
| G3 | 通过 | 场景 300000，初态与几何核验，50 行后第二次请求。 |
| G4 | 通过 | 场景 100000 与 G1 匹配，官方选择器对共同替身块选择 50。 |
| G5 | 通过 | 场景 200000 与 G2 匹配，官方选择器对共同替身块选择 50。 |
| G6 | 通过 | 场景 300000 与 G3 匹配，官方选择器对共同替身块选择 50。 |
| G7 | 通过 | 对照 G2 的真实 CPU 初态，首请求字段相符，实际测量 tick 0。注入第 3 策略步预算停止，hold、close 和场景退出凭证齐全。 |

另在 G5 场景输入带速度谷值的合成动作块，官方 PACE 选中 17 行，实际 CPU PhysX 在第 17 行后完成第二次请求。

三对 H50/PACE 的同场景首请求字段逐项相同，包括完整 prompt、14 维状态、相机名称、形状与 dtype。三路占位图像均为 `uint8 (3, 240, 320)`。GPU 将实际校验三路非恒定帧、原生成功谓词、有效模型收据、首请求与响应哈希和独立 JAX RNG。CPU 结论不等于这些现场条件已通过。G7 的 3 步上限仅用于注入测试，部署仍用冻结的 130,000 步。

21 项定向回归全部通过，包含固定上游 rollout、800 动作边界、真实 WebSocket 替身、JAX RNG 语义替身及安全退出。定向测试检查了七项完整授权前无 release、提交回执丢失时按精确批次标记找回、授权失败撤回本批次持有项、重复批次停止、release 局部失败保留已经放行的作业，以及一个试次故障或超时后其他进程仍可运行。既有 100000 原生与保护侧回归和旧压缩包哈希保持独立。实际 CPU 记录、路径和复现见[证据目录](../research/g2/parallel-batch/README.md)。

在实际 SCNet 部署目录复查 PACE 与 Openpi-PACE 的提交及跟踪文件，复查模型 CPU 收据、28 个冻结文件的尺寸/时间快照、norm stats 和 tokenizer 哈希。兼容集群 Git 1.8.3.1 的只读检查已通过。[集群证据](../research/g2/parallel-batch/cpu/scnet-scheduler-test.json)
