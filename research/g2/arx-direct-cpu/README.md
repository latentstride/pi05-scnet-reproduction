# Direct ARX control, CPU acceptance

The opt-in `arx_direct_v1` standalone trial retains the existing source FK/IK for policy coordinates and target ARX FK/IK for motion. It does not instantiate the Aloha collision proxy or invoke the recovery coordinator or TCP projection. A policy chunk has at most 24 sequentially admitted rows. Each row is planned from a new measured ARX start and executed using the existing contact, collision, joint, velocity, acceleration and tracking checks. The first measured finger contact, a holder transition, a predicted contact/release boundary or an already active contact ends the prefix and triggers a new policy exchange. Stop on an unsafe candidate or actual state. The model's training and native task predicate are unchanged.

The historical Q113 comparison uses job 127737638 at tick 33895. The old source check rejects row 4 on the right proxy link against the table. The direct route executes rows 1–6 through tick 34155. The historical Q14 target check at tick 6145 rejects row 9 on predicted ARX finger/block penetration and holds at the same tick. See the full [Q113](q113.json) and [Q14](q14.json) receipts. These headless reconstructions restore recorded geometry and drives, with zero initial velocities and fixture RGB.

The [full uninterrupted run](expert-full.json) passed the native predicate after 28,100 PhysX ticks and 244 expert rows (plus existing placement suffix). Left hold, shared hold, right hold and release were measured at ticks 7001, 18343, 20319 and 27565. Two 24-row approach prefixes completed. The replay took 566.5 wall seconds. The model and rendered RGB were not exercised, so this demonstrates physical reference feasibility and safety, not a policy success.

The expert replay uses the archived seed-1 mapped ARX reference and the raw source frame clock. The [480-second run](expert-480s.json) reached sustained left hold at tick 7053, shared hold at 18386 and right-only hold at 20355, all in one scene. The initial source-joint interpretation experiment is retained as [negative evidence](bound-source-trace.json). The archived experts are used only in the CPU harness, never in policy inference. Placement uses the existing live expert placement suffix on the same scene and the frozen PACE check_success body with the fixture's block/tray functional points.

CPU execution uses the existing RoboTwin CPU container with the candidate scripts, the archived standalone release on Python's import path and `research/g2/final-system-review/arx_replay.py`. Invoke `g2_arx_direct_cpu.py RELEASE ASSETS OUTPUT REFERENCE_NPZ` with the SHA-bound `tools/g2-settle-expert-20261106/workspace-q.npz`. The collision replay command is `g2_arx_direct_collision_cpu.py RUN RELEASE ASSETS OUTPUT QUERY`. No GPU allocation or model inference participates in these CPU tests.
