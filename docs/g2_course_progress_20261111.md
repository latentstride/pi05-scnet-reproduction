# π₀.₅ × RoboTwin 项目进度与课程展示

课堂主线是把两种本体的异构示范变成**可核验的数据集、可比较的几何指标和可追溯的闭环证据**。目前已完成 100 条示范的数据处理、47,628 个单臂目标的几何筛查和六条原生 Aloha 实跑分析。ARX 投影作业 `127620967` 已提交，本文仅使用历史归档和 CPU 验证结果。本轮 GPU 提交数 **0**。

| 阶段 | 进度 | 已取得的证据与待验收项 |
|---|---|---|
| 1. 官方复现 | 已完成 | 官方 `pi05_libero` 在 3 个 spatial 任务各 5 个初态完成 15/15 的受限基线。其任务、权重和结果单独保存。[冻结记录](../baseline_freeze.md) |
| 2. 选定跨本体实验 | 已完成 | 固定 RoboTwin 2.0 `handover_block`，以 Aloha-AgileX 为源、ARX-X5 为目标，审计任务级 PACE 权重和接口。[选型与数据对照](../dataset_comparison.md) |
| 3. 异构数据处理 | 已完成本批数据 | 两本体各 50 条专家示范，23,814 帧、95,256 张图像。完成 HDF5 字段审计、状态与姿态规范化、CRC 和 SHA-256 校验。保留重复帧和空字段记录，按帧索引表达时序。[全量处理报告](../research/robotwin100_course/REPORT.md) |
| 4. 动作空间与坐标统一 | 适配与 CPU 验证完成，动态迁移待验 | 校验关节顺序、任务坐标系、TCP 和夹爪语义；完成双向 FK/IK 筛查。历史 ARX 阻断后，两个独立快照的投影前缀分别执行 495 和 610 个 CPU 物理步并进入新请求接口。冻结模型在真实新观测上的连续控制待测。[适配规范](../robotwin_control_adapter_spec.md) · [投影 CPU 验证](g2_arx_projection_online.md) |
| 5. 模型适配与源本体闭环（修订后的原微调阶段） | 已完成源端验收 | 冻结 PACE 任务权重完成真实推理与原生控制。三个场景中 Fixed H50 成功 3/3，PACE 成功 2/3。[原生闭环回执](g2_aloha_six_results_20261111.md) |
| 6. 跨本体仿真评测 | 进行中 | 历史 `127510363` 在接近阶段停止，ARX 专家轨迹在其夹具下提供任务可行性参照。现行投影试次须回读真实相机、模型响应、实测抓持和原放置谓词，方能判断目标闭环结果。[历史 ARX 对照](g2_aloha_to_arx_cpu_20261111.md) |
| 7. 消融与总结 | 材料与工具完成，实验结论待补 | 已有冻结条件、离线分析、展示图和复现说明。六条原生实跑可用于描述性比较。原生首块输出未对齐、目标本体仍待实测，跨本体效果和控制变量消融尚未完成。[评测口径](../experiment_protocol.md) · [图表与复现](../research/g2/course-analysis/README.md) |

冻结权重把问题收敛为下游迁移。在同一任务模型下，研究可分别检查数据格式、坐标与关节语义、规划可行性、接触动态和重新观测后的策略响应。历史失败已定位到源代理碰撞和 IK 连续性，已有证据不足以判定需要重新训练。此时加入混合数据微调会同时改变权重、训练分布和控制接口，使端到端差异难以归因。阶段 5 因此改用既有任务权重验收源本体，阶段 6 再验证目标本体的观测与动作适配。ARX 投影条件采用冻结模型加受约束动作重定向。

建议按数据流展示四张图。先展示两本体各 50 条轨迹的记录长度与重复状态，再展示双向 IK 的尝试数、分母和残差。随后用 G1–G6 说明几何可解与动态完成的区别，最后用 G3/G6 的逐步曲线解释失持定位。结束时用历史 ARX 的 36 次查询说明如何从回执追到碰撞对与停止原因，明确当前目标作业仍需实测结果。课堂成绩表分列 LIBERO、原生 Aloha、ARX 专家和 ARX 策略四种证据，保持各自分母。
