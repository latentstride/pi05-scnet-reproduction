# G2 双指中心反馈修复 · 2026-11-06

修复对象是原10g任务中，ARX夹物后两指独立饱和驱动造成的中心漂移。保留5mm/5°累计滑移阈值、原首次抓稳锚点、双侧每指2N上限，以及原119.116/110.052/115.188s重定时参考。

## 控制改动

原驱动分别计算`clip(K*(target-q)+D*(v_target-v), ±2N)`。闭合目标0被物块挡在约30mm时，两边未经限幅的闭合力约30N，均饱和为2N。此时小幅两指中心偏移不会改变输出，中心方向缺少恢复作用。提高相同力上限没有解决该控制死区。

新`g2_finger_force.centered_finger_force`先分解平均闭合量和双指差分，先限制共同闭合力，再叠加差分中心反馈，最后逐指限制到±2N。沿用K=1000、D=200；没有增加碰撞豁免、固定约束或抓稳后的锚点重置。实际两指仍分别测量和记录。

新模式`bounded_aperture_center_force_v1`显式关闭内建指PD驱动，保留其目标字段作为模型闭合意图，在每个4ms物理步提交计算后的有界关节力，避免重复施力。重力/科氏被动力补偿单列叠加，2N约束指控制器分配的棱柱关节控制力，不能解释为包含被动力补偿的总关节力上限。实际分配力以`finger_force_4ms`保存。

生产`ARXBackend`已接入相同控制函数，并在每个物理子步更新；hold保留持物手闭合意图。`g2_task_runtime`新增经标定物块质量检查，带`validated_block_mass_kg=.01`的配置遇到0.72kg负载会拒绝，避免沿用历史夹具参数。
