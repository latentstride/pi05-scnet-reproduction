# Aloha seed1 CPU 动力学重放与固定手腕对照

## 结论

**H50 已通过真实抓持与滑移的 CPU 重现验收。固定左腕驱动后仍发生滑移，而且早于原始动作分支。** 因此，原始后续手腕指令不是该次滑移的必要条件。证据将优先排查范围收敛到持续闭爪时的接触/物块就位稳定性，以及持有锚点建立时序。现有两分支尚不能进一步区分夹爪驱动、摩擦、接触求解和锚点判定的独立贡献。

K31 复查重现了首次左持，但未通过原停止时刻及全段物块轨迹的预设误差验收，因此没有执行 K31 固定手腕分支。结论范围为这一次冻结 H50 seed1 轨迹。

## 实际执行与版本

本轮在既有集群环境中运行纯 CPU `PhysxCpuSystem`，SAPIEN `3.0.0b1`、mplib `0.2.1`。没有创建 renderer、执行模型推理或进行 GPU 作业操作。所有新数据保存为独立 CPU 诊断，原 GPU 作业 127147943、冻结阈值、配置和 checkpoint 保持原证据状态。

控制语义直接从冻结 PACE `fd2e624cc19325cc9b20a620c82d51c0d8e25cc1` 提取 `Base_Task.take_action()` 与原生 `Robot` 控制方法，包括 TOPP 位置/速度、夹爪插值、速度目标和被动力补偿。只移除相机更新与未到达的成功渲染分支。逐步重建的 **5139 / 4777 个位置驱动与指驱动均与原 GPU 日志完全相同**。速度驱动依同一固定源码和 TOPP 重建，原日志没有单独保存该字段，不能声称与未记录的速度字节直接比较。

无渲染物理场景使用生产资产目录中的冻结 URDF 和网格，保留源任务的桌面厚度 0.05 m、桌腿位置、墙、地面、静态目标及动态物块。所有连杆按原任务设置质量 1 kg，物块按 `Actor.__init__(mass=0.01)` 设置 0.01 kg，驱动参数为原 1000/200。以完整冻结初态和零速度重置后，从第一个控制步开始推进，未通过设置抓持终态来代替前缀执行。

建立环境时曾在物理步开始前遇到两个问题，均保留记录。第一次入口指向只含元数据的资产目录，缺少碰撞网格；第二次发现直接创建 PhysX 碰撞体没有包含原 `Actor` 包装器的质量赋值。最终重放使用实际生产资产和原包装器质量。它们是场景重建修正，不是改变原物理参数。

## H50 固定手腕分支

两分支均从完整初态独立重放。**从 tick 1 至 5088 的全部记录完全一致**，包括实际关节、物块、接触冲量和驱动。干预从 tick 5089 开始，冻结左臂六个关节的位置驱动为 tick 5088 的值，并将其速度驱动设为零。夹爪及右臂保持原来的逐物理步驱动时序。

这里的固定手腕是伺服保持，仍允许受力产生小幅实际位移，未添加物理焊接或修改惯量。该干预同时去掉后续左臂位置指令变化和速度前馈，不能单独估计两者的贡献。

固定分支在首次左持后 **44 tick，约 0.176 s** 触发相同滑移保护。原始分支在 **51 tick，约 0.204 s** 触发。固定分支先停止 7 tick，约 28 ms。两者分别在各自第一次安全停止处结束，未继续执行停止后的驱动。

固定分支停止时，左指实测约 30.127 / 29.648 mm，指驱动约 14.584 / 14.584 mm，仍在继续闭合；两指接触冲量模长和除 dt 分别约 15.646 / 15.668 N。它是接触冲量统计，不能等同于执行器输出或据此认定摩擦不足。物块从首次左持起移动约 4.789 mm，远大于同时段工具的 0.184 mm 位移。

## 证据判读与下一步

- **CONFIRMED**。这一次 H50 seed1 的连续控制、抓持形成和滑移可在 CPU 上重现。固定后续左臂驱动仍导致滑移，因而“必须由原始后续手腕运动才能导致滑移”的解释被本对照否定。
- **SUPPORTED_HYPOTHESIS**。持续闭爪中的物块接触就位、转动和锚点参照不稳定，比继续更改动作窗口更值得优先排查。固定分支手腕实际移动更小，物块依然发生约 5 mm 相对漂移，符合这一方向。
- **UNKNOWN**。尚不能认定接触门禁是误报，不能证明只要推迟建立锚点就能稳定抓持，也不能确认主因究竟是夹爪预载、摩擦、接触几何还是求解器。没有移除保护观察停止后的演化，也没有完成整个任务。
- **UNKNOWN**。K31 的尾段未通过复现验收，H50 结论不能直接推广至 K31、其他初态或完整 Aloha→ARX 策略。

本次无需增加 GPU 试次。后续最小 CPU 因果检验应在已通过的 H50 重现状态上，进一步隔离闭爪预载与接触就位时序，并保留原保护。此处只提出方向，当前交付没有实施第三类动力学干预。
