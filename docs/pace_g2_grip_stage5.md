# G2 第五轮：独立双指状态映射修复

日期：2026-11-05。CPU开发与验收，不申请GPU。

## 问题与修复

ARX固定URDF的joint7/joint8是共用link6、相反单位轴、无mimic约束的独立平移关节。物块偏心或接触力矩可以使两指实际位置不同。旧标量接口把这种情况误当作mimic失配；20N提起终点差异1.455mm因此阻断后续观测。

新增显式 `independent_aperture_v1` 合同，加载时核对无mimic、同父连杆、同关节旋转与反向单位轴。每指分别检查物理限位及标定行程，原0.001m容差不扩大。只有显式配置启用该合同，旧strict模式保留拒绝测试。

设两指实际外移量为q₁、q₂，标定闭合值c₁、c₂，张开值o₁、o₂，策略夹爪标量为：

`g = ((q₁-c₁)+(q₂-c₂)) / ((o₁-c₁)+(o₂-c₂))`。

这保留相对闭合端点的总开口增量，而单个标量无法表达开口中心偏移。日志同时保存实际两指、等开口的对称代理、每指约简残差、中心偏移、原始归一值和是否边界截断。它是明确的几何约简，不把实际位置改为驱动目标，也不改动物理关节或碰撞几何。

20N终点实际值28.838/30.293mm，对应归一值0.6719438613，等开口对称代理29.566/29.566mm；每指残差约±0.727mm。两指实际值保留；不能把对称代理当作测量。

## 撤离阻挡的根因与碰撞规则一致性

隔离125步CPU物理对照发现，原生URDF形状过滤组全为[1,1,0,0]，PhysX在base_link/link2产生约8 N·s的接触冲量，使joint2停在约−0.2303rad；规划器则按固定 `curobo_tmp.yml` SHA `07c7faf92f6c9c7e3b7c370cb4487494d236935910cf6d89333f89f0b56c0ddb` 忽略此对。相同驱动及目标下，对齐该规则后，joint2达到−0.31855348rad，目标−0.31855384rad，误差约3.6e−7rad。证据 `research/g2/physics-parity-20261105/`。

实现 `apply_audited_arx_physics()`：每个原生忽略对使用独立位，每台机器人分配不同过滤ID；保留类型/亲和组和其他场景对象过滤设置。在任何写入前逐一验证全场景形状对：仅已审计的同一实例内部忽略对可改变。已有非零物理忽略配置则拒绝覆盖，写入失败回滚。元数据保存规则SHA、全部变更前后值及形状对检查数。

刻意重叠双臂和障碍物的25步物理测试通过5项检查：跨臂和环境实际接触仍产生，环境过滤值不变，base_link/link2按原生表过滤，未列入表的link2/link5仍启用碰撞；171对形状过滤关系验证通过。本地另有过滤矩阵、未请求机器人、预配置拒绝及写入回滚的单元测试。

此处有明确的仿真约定：物理引擎与规划器均采用固定资产的原生self-ignore表。它并不证明这些CAD网格在所有位姿都没有重叠。与未应用该规则的历史对照分开保存，正式实验必须冻结同一约定；该夹具不能作为实体机器人安全证明。

参考：[SAPIEN 3 PhysX碰撞过滤契约](https://sapien-sim.github.io/docs/api/sapien.pysapien.physx.html)。

## 持物预测与累计滑移参考分离

原持物预测沿用首次接触确认时的相对变换；物理接触形变仍在5mm/5°容差内时，旧参考也可能让预测几何误报超过2mm穿透。现在 `holders` 保持最初抓稳参考，用于累计滑移检查；`measured_attachments` 每物理步记录实测工具/物块关系，用于下一候选位姿的碰撞预测。实际状态检查继续使用物块实测世界位姿。

新增回归：相对参考移动3mm时，预测使用该实测变化，初始参考不变；随后累计到6mm必须报滑移，不能通过逐步更新参考绕过限制。原5mm/5°滑移、2mm实际接触和2mm/2°双持闭链容差未放宽。

第八轮完整CPU物理夹具8/8项通过，3023步，命令50mm/实测44.945mm提起，正常退出0。最终完整证据与作用域见 [交接验收报告](pace_g2_handover_acceptance.md)。
