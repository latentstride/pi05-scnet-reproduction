# G2 最终 CPU 修复与回归

Aloha 的候选配置显式启用 physical_aperture_v1。新增 NativeReleaseTracker 继承原接触确认和滑移实现，只改变原生张爪判断。负闭合预载先转换为距标定闭合端的物理开度，再按同一持物区间的最小开度累计判断。微量预载变化不被标记成释放，连续微量实际开度增加仍会触发原比较阈值。真正提前张爪受阻，接收手确认后允许释放，意外接触丢失仍报错。候选未通过时不提交释放状态。候选拒绝额外记录实际关节、实际手指、前后驱动与检查段位置。

首次回归发现，直接修改共用 ContactTracker 会打破 ARX 中心力控的历史源码凭证。最终实现把 Aloha 语义移入单独子类，ARX 的已校准跟踪器保留原始字节，原 ARX 证据回归继续通过。

ARX 的有界恢复及自由空间 RRT 现在也拒绝尚未确认持物的实测指尖接触。策略回复在支持 infer_raw 的客户端先保存原始响应，再验证数组，使异常回复可追溯。原安全规划、接触力、滑移、限位、物体位姿与真实重采集合同保留。历史四个精确目标仍拒绝，原有四条有界恢复、真实网格绕障和三条静态放置后缀继续作为对应层级证据。

候选方案提供独立准入和单共享进程监督演练。CPU 替身验证原生任务失败后已准入的 ARX 仍可运行、未准入记为 not_run、硬超时和模型退出时收尾。全量回归 201 项、合成 episode 13 个通过，保留原有 188 项覆盖。验收日志与运行清单位于 final-cpu-review，合成 episode 仅用来检查控制接口。

证据分层如下。

- 真实 CPU 动态证据来自既有专家回放与历史物理归档。重新分析 K26 的真实连续接触序列属于离线重放。
- 本轮新运行的真实几何是 SAPIEN/FCL 静态复查，六个候选碰撞检查点零物理步。它确认历史拒绝，不证明新路径动态可执行。
- 新原生释放语义、ARX 接触门槛和统一监督逻辑完成 CPU 合成或回归验证。新原生接触后连续执行、ARX 动态恢复和专家放置段现场切换尚未取得实机等价结果。
- 真实模型跨本体成功率、在同一分配中的资源与性能和完整交接尚未验证。
