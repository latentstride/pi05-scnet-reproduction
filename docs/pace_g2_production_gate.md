# G2 生产规划门禁 CPU 验收

真实 ARX 网格、原任务 10g 物块和生产规划/执行模块的门禁功能 16/16 项通过。动态试跑完成交接，在 CPU 截止前未完成放置。归档参考轨迹的放置段另有可复现的阻断。实测右指以及驱动目标投影后的右指均与托盘重叠，现行门禁正确拒绝。

本轮用 SAPIEN PhysX CPU、MPlib FCL 和固定资产。端到端调用链为 `g2_run_task.execute → Adapter → QuinticMotion → ContactWorld → ARXBackend`。相机输入由零图替代，动作来自固定专家记录。10g 场景由 CPU 验收脚本重建，稳定后的关节和物体位姿与已归档的原任务参考一致。

## 功能检查

- 实测初态可通过几何门禁，双臂互碰及右指碰托盘会被拒绝。
- 闭合意图仍为每指 0，抓取检查点的预测开度为 29.088mm / 29.111mm。直接检查闭合端点会被拒绝，使用预测开度可通过。
- 持物与障碍物碰撞、双手闭链不一致、接收手确认前松开均被拒绝。双手持物时，先松手再撤离，候选物体位姿检查后恢复。
- 在生成有效计划之后移动障碍物，执行器在第一个物理步之前拒绝。记录为 0 次控制调用、0 物理步，并保存碰撞对。双臂 hold 后速度目标归零，环境退出。
- 优化版在每组固定手臂关节候选内复用持物预测位姿。单手和双手检查点均对照旧扫描，预测开度和修正记录逐值相同。单手和双手检查分别从 36 和 64 次物体位姿上下文更新减少到 1 次。

## 放置段阻断

从成功的中心反馈直驱回放中恢复第 28,000 至 28,320 步的七个实测检查点，分别检查实测几何和该时刻驱动关节与预测指开度。前三点均通过，后四点两种检查均拒绝。第 28,160 步右指 link7 对托盘的实测 FCL 重叠为 0.000919mm，驱动候选投影后的重叠为 1.403mm。后续候选的最大重叠为 2.411mm。首个 PhysX 指与托盘冲量记录在第 28,157 步。

七个点是实测记录的几何复查。当前规则允许满足深度限制的指与物块、物块与支撑面接触。机器人与托盘不在允许集合内。放置路径仍需规划出手指避开托盘的动作，才能通过这一门禁。
