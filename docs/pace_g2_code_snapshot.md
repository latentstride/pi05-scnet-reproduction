G2 代码快照包含跨本体适配、接触控制、生产门禁、初态配对、单作业入口、回归测试及阶段报告。scripts/g2_graphics.sh 和 scripts/g2_host_supervisor.py 是冻结 r2 实际运行的生成文件，其源码字节与验收清单一致。

公开副本中的部署绝对路径已替换为 <PROJECT_ROOT>。发布报告中的 SHA-256 指向 SCNet 原始冻结包，公开脱敏记录的字节会与原始记录不同。

部分测试读取 research 下的完整专家轨迹、HDF5、物理回放和生产场景证据，需要原研究工作区的数据。此代码快照保留这些测试，运行完整 149 项回归前需要恢复相应数据。公开仓库包含参数配置和精简结果，原始数据、模型与运行视频保存在研究工作区。

最新同步及188项完整数据回归的范围见 [G2聊天研究进展同步](g2_chat_sync_20261106.md)。
