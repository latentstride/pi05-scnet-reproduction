## 本次实现

- `g2_kinematics.py`：固定 URDF 哈希校验、六关节名称/顺序核对、解析几何雅可比、有限多种子阻尼 IK、位置/姿态残差和奇异性检查。接受阈值为 0.5 mm / 0.05°，最小加权雅可比奇异值 1e-5。IK 搜索失败记为 `ik_failed`，不据此宣称不可达。
- `g2_assets.py`：复用现有资产审计，校验 URDF/config；工具外参、关节控制边界、每指闭合/张开标定均须显式提供。指端点必须位于 URDF 限位内。
- `g2_capture.py`：从 articulation 的 active joint 名称和实际 qpos 取状态及实际根位姿，从三路 RGB 组装同步快照。调用方须提供权威物理步时间戳并暂停推进场景。本地通过替身对象验证，尚未在真实 ARX 场景调用。
- `g2_adapter.py`：ARX 实际状态 → 共同任务工具位姿 → Aloha IK 代理 14 维状态；绝对 50×14 动作 → Aloha FK → ARX IK → 同步双臂轨迹。检查跨 reset、过期相机、名称/侧别、mimic、一致性及限位；失败结果 payload 为 null，不推进成功代理种子。允许有界夹爪截断时记录原始值、规则、最终归一值和每指 native 目标；超出允许包络拒绝。
- `g2_motion.py`：双臂与四指统一时间轴，各 waypoint 停止的五次多项式重定时，解析速度/加速度上界、细分碰撞采样、tick 预算保护。碰撞 checker 必须由调用方注入，当前验证使用 Mock。它是直线关节路径规划，遇到碰撞拒绝；没有绕障搜索，也没有 CuRobo GPU 通过声明。waypoint 顺序保留，接触事件停留/持物约束尚待实装。
- `g2_episode.py`：统一策略客户端，窗口 1/4，独立 expert_qpos 几何路径入口；保存三路图像、实际状态、代理状态、原始动作、适配请求与 IK 诊断、重定时轨迹、控制回调日志、耗时、视频和退出原因。异常进行 hold/清理，逐步事件可恢复；最终证据写入失败也先执行 hold/close。每份结果标明 data_kind，当前拒绝 formal 执行。墙钟超时目前为协作检查；不可中断的原生调用仍需外层子进程监督。失败部分执行以逐步事件为准，`executed` 只统计完整返回的动作前缀。
- `g2_cpu_preflight.sh`：仅 CPU 测试、名义工作域筛查和持久化 Mock episode 的统一入口，不包含资源申请命令。
- `pace_runtime.py`：新增 `infer_raw`，让 G2 在校验模型动作形状前先保存非法原始输出；原有 `infer` 仍执行原来的请求/响应校验。真实 WebSocket 错误形状的留证已通过测试。
- `verify_robotwin_fk.py`：把 h5py 导入和输出目录创建移入 main，使几何链可在无 HDF5 依赖的 CPU 适配器中复用。FK 数学不变。

Mock 的工具外参、基座配准、指端点、速度/加速度和无障碍判断均为**合成夹具**，仅在 tests 中构造。它们不构成真实控制配置。
