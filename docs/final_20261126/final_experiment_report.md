# π₀.₅ → ARX-X5：七阶段最终实验报告

更新：2026-11-26（Australia/Sydney）。任务：RoboTwin `handover_block`。最终运行：`step5-openpi-clean150-20261126-v1`。本报告依据已保存结果离线整理，本次归档没有启动 A800 或无卡实例。

## 1. 最终结果与研究结论

以 PACE handover_block π₀.₅ 基座为起点，使用新采集的 150 条 ARX-X5 clean 专家示范微调，EMA step-2000、H50/K15 在原始初态 seed 0–9 原生闭环中达到：**10/10 自主抓起、8/10 右手独立交接、7/10（70%）官方完整任务成功**。稳定双指持物最大净抬升为 **161.08–212.80 mm**。七条成功轨迹完成抓取、交接、松爪放置，并触发 `env.check_success()`；由实时三路观测产生模型动作，没有专家接管、人工对准或夹爪覆盖。

这是**经目标本体 ARX 数据微调后的迁移适应成绩**。原生 ARX 微调、ARX/Aloha 混合训练基线和冻结 Aloha→ARX 状态/动作映射是三条独立路线；冻结路线的历史局部抬升不计入本报告最终模型成绩。现有结果支持该任务上的目标本体适应，未开展多任务或真机评测。

第 2000 步 seed 0–4 成功 3/5，达到预设早停条件，随后同一 EMA/K 补测 seed 5–9 成功 4/5。没有继续训练第 3000 步，也未执行其条件性的 K8 对照。seed 0–4 曾用于历史模型摸底，因此 70% 是这十个指定初态的实测结果；独立 HDF5 Test 划分与这些仿真 seed 的概念分别记录，不将十场表述成未接触的统计泛化基准。

## 3. 最终数据与模型配置

### 数据

- 新增 Train 为 **150 条 clean ARX**，来自 seed1000起顺序尝试；复用已校验seed1000一次，另154次尝试取得149条，末个接受seed1154。每条官方专家成功、14维动作、三路240×320×3 RGB、六阶段事件均校验。原50条全部seed被排除。
- 最终Train仅新150条，**不再混入旧40条**。保存帧数实际274–319、均值282.49；seed1000为303。采集沿用demo_clean/save_freq15、0.6m双臂间距、无domain randomization，逐物理步重力补偿；保存行间隔仍以真实tick为准。
- 原5 Val/5 Test不变。Val episode `[7,18,23,31,43]` → scene seed `[7,20,25,33,45]`；Test episode `[6,29,33,38,48]` → scene seed `[6,31,35,40,52]`。episode编号不等于scene seed。
- 新H5 SHA256：`4f4c7a366658b2db9014e1188f3029e7990a97713b9b75eff81a6ab9889b4453`。新q01/q99只用150Train，使用与terminal=True读取器一致的H50下一保存行目标及末端edge padding；原50/190 H5未覆盖。
- RGB/BGR预检通过，无额外通道反转：seed1000红块RGB均值[226.11,3.09,3.25]，蓝垫[0.96,1.23,254.08]，与原clean解码方向一致。

## 4. 评测协议与同口径总表

原生`env.take_action(row, action_type="qpos")`、原生TOPP及`env.check_success()`；600行动作上限。保留初始化/逐物理步重力补偿，使用原生机器人驱动，无G2候选FCL熔断、持物/闭链/丢接触熔断及QuinticMotion。PhysX真实接触仍然存在。qpos执行使用Mplib/TOPP初始化，不调用专家CuRobo路径。

抓起定义：至少0.2秒连续双指实际接触、无桌面等支撑，物块中心相对本场初态净抬升≥30mm。右手独立交接：此前左手抓起，右双指接触、无左臂接触、无外支撑持续≥0.2秒。官方成功单独采用原任务谓词：功能点 **每个水平轴绝对差<30mm**、竖直绝对差<10mm、右夹爪张开；不是欧氏水平距离<30mm，也没有额外成功稳定时长。视频不替代物理日志和原生谓词。

## 5. 关键问题、证据与改进范围

1. **初始化重力补偿遗漏。** 同seed A/B仅恢复原生两臂被动力调用、命令不变：drive/actual TCP差23.69199→0.009364mm，姿态3.75389→0.001192°；三相机首帧MAE也下降。证明该遗漏制造了初态观测偏移；修复后早期模型仍抓取失败，不能称它单独解决策略学习。[原始A/B](../../research/final_20261126/historical/initial-gravity-counterfactual.json)
2. **自定义护栏改变评测口径。** 历史链含候选腕部/自碰撞FCL预检、5mm/5°滑移、1nm张开增量、2mm/2°闭链、单帧接触丢失与QuinticMotion逐点停顿等额外停止条件。action61左夹爪0.0021307→0.0023208只使每指目标微增8.36μm，仍近闭合，却触发1nm释放规则。先独立修正该误杀，后新建原生评测完全绕开这些链路；未修改原文件阈值来抬高最终分数。[数值与源码](../../research/final_20261126/historical/randomized-data-and-donor-audit.txt)
3. **预测不等于执行，离线TCP不等于完整抓取。** 单动作13原始H50/解码/裁剪对照差0，裁剪前后首次闭爪均0-based27，独立几何支持候选张爪与物块相交；该次不能归因解码器或错误保护。重复小对照、单点位置误差优化都未形成自主抓取证据，原归因保留。[action13](../../research/final_20261126/historical/action13-attribution.md)
4. **数据采集与训练时间语义。** CuRobo/Warp打通后单进程常驻批采150条原生成功示范，六阶段完整，RGB方向校验通过；统计仅用Train重算。固定save_freq不能消除事件边界的非固定物理间隔，H50表示未来50个保存行，K表示执行行数。[采集与映射](../../research/final_20261126/collection-manifest.json)
5. **最终训练与块长联合改进。** 放开视觉与动作专家、原生Flow等权、EMA0.99、K15形成有效最终系统。旧2500仅改变K已从0/5到2/5，说明重规划时机值得对照；不能仅凭后缀闭爪或最终成功就断言一种固定“正确物理时间”。
